たのてつサポーター & チームたのてつ LP（提案版）
=================================================

■ 見かた
  1. zip を解凍します（フォルダのまま使ってください）
  2. フォルダ内の index.html をダブルクリックすると、ブラウザで開きます
     ※ css / js / images フォルダを index.html と同じ場所に置いたままにしてください

■ フォルダ構成
  index.html      … ページ本体
  css/style.css   … デザイン
  js/main.js      … メニュー開閉・スクロール演出
  images/cover.jpg   … 番組ロゴ（カバーアート）
  images/circle.svg  … チームたのてつのイラスト

■ 補足
  ・発表回（#178）の動画は、ダブルクリックで開いた状態ではクリックするとYouTubeが新しいタブで開きます。
    サーバーに置いて公開すると、ページ内でそのまま再生されます（YouTubeの仕様による違いです）。
  ・ロゴ画像（images/cover.jpg）は番組YouTubeチャンネルのアイコン画像です。正式素材をもらえたら同名で差し替えてください。
  ・フォント（Zen Maru Gothic / M PLUS Rounded 1c）は Google Fonts から読み込みます。
    オフラインのときは端末の丸ゴシック系フォントで表示されます。
  ・申し込みボタンは、品川さんのnote記事に掲載されている公式の Stripe 申し込みページに直接つながります。
  ・ページ上部の黒帯と、フッターの「非公式の提案版」表記は、
    運営チームが正式に採用する場合に削除・変更してください。
  ・サーバーに置く場合は、このフォルダをそのままアップロードすれば動きます
    （Netlify / GitHub Pages / Cloudflare Pages などにドラッグ＆ドロップで公開可能）。
